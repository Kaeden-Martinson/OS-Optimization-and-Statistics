In-game overlay

The overlay that sits top-right while you play, in the Instrument style. Each option is shown over a dark scene and a bright snow scene (Starve.io has both), because that's where readability breaks. The amber CPU value is the warning color doing its job.

Panel: the full readout with a frame-time trace

A small ruled box like the app's grid. Large FPS, then a live frame-time trace (spikes show as stutter), then GPU, CPU and memory rows. It shows the most, and it's the tallest.
