Optimizer page

Three ways to lay out the system checks, using the checks the app really runs. The values are examples, not readings from your PC: two checks are set to need action (Background recording on, Edge on the Intel graphics) so you can see how each layout handles that. Light/dark switches are in each window's corner, or flip them all at once.

Setting, current value, recommended value, what it costs you, and a button, all in one ruled table. Rows that need action get an amber edge. You can compare everything at a glance; the explanations are short to fit.
