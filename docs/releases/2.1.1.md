### What's new

**A tidier Strip.** The in-game Strip has even spacing now: every cell has the same padding, each label sits next to its values, units sit next to their numbers ("20 FPS", "64° 4%"), and all readings share one baseline. The POWER/slowdown label has its own cell with the same gap as the others. Only the temperature turns amber or red when it's high, not the whole reading. The width still never changes as the numbers do.

If you're on 2.1.0, Settings › Check now offers this update.
